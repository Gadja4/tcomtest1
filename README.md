# TCOM · Pregătire test grilă laborator

Site static pentru pregătirea testului grilă de laborator TCOM (UTCN): **10 întrebări în 10–12 minute**, fiecare cu 0, 1, 2, 3 sau 4 variante corecte.

## Ce conține

- **⏱ Simulare examen** – 10 întrebări aleatorii din 177 (Laboratoarele 2–7), cronometrate, cu probleme de subrețele generate la infinit. La final: scor strict, scor pe variante și explicația fiecărei întrebări.
- **🃏 Flashcarduri** – 75 de carduri cu ce trebuie știut pe de rost, filtrabile pe laborator.
- **📘 Ce învăț** – paginile importante din fiecare laborator (cu nivel de importanță), plan de învățare, metode rapide de rezolvare și tactica la test.

## Folosire

Deschide `index.html` în browser sau accesează versiunea publicată pe GitHub Pages. Nu necesită instalare și nu salvează nimic.

> Material neoficial, făcut pentru pregătire. Verifică întotdeauna cu fișele de laborator.
